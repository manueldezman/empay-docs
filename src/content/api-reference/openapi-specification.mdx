The EmPay API follows OpenAPI 3.0.3. Use the specification to:

- Generate client libraries.
- Import the API into testing tools.
- Integrate the API with AI agents and other developer tools.
- Build automated documentation and contract tests.

## For AI agents

AI agents can discover and consume the API documentation through these public
resources:

| Resource | URL | Purpose |
| --- | --- | --- |
| OpenAPI specification | [`https://empay-api-docs.thally.app/openapi.yaml`](https://empay-api-docs.thally.app/openapi.yaml) | Complete structured API contract |
| `llms.txt` | [`https://empay-api-docs.thally.app/llms.txt`](https://empay-api-docs.thally.app/llms.txt) | Concise documentation discovery index |
| Full LLM documentation | [`https://empay-api-docs.thally.app/llms-full.txt`](https://empay-api-docs.thally.app/llms-full.txt) | Complete documentation in one text resource |
| Documentation index | [`https://empay-api-docs.thally.app/api/docs-index`](https://empay-api-docs.thally.app/api/docs-index) | Structured JSON list of published pages |
| MCP server | `https://empay-api-docs.thally.app/api/mcp` | Exposes documentation search and retrieval as agent tools |

Individual pages are also available as Markdown, JSON, and JSON-LD.
