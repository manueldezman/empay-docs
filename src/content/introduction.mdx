Build employee self-service portals, internal HR tools, and payroll integrations
with one role-aware REST API. EmPay covers employee management, attendance, leave,
payroll, dashboards, notifications, settings, search, and audit activity.

<Info>
  This documentation is a portfolio demonstration backed by a simulated API
  environment. It does not expose production EmPay systems or employee data.
</Info>

## Start with a working request

Follow the [Quickstart](/getting-started) to retrieve fictional attendance data
with a public demo token. You will see the exact request, expected response, and
success criteria.
