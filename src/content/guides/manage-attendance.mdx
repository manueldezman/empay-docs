---
title: "Retrieve monthly attendance"
description: "Use the mock bearer token to retrieve deterministic monthly attendance records."
---

Use the hosted read-only workflow to retrieve fictional attendance records for a
selected month. The endpoint is stateless: it never creates or changes employee
data.

## Before you begin

You need a bearer token. Follow [Authentication](/authentication) before calling
protected attendance endpoints.

## Retrieve the month

Pass a calendar month from `1` to `12` and a four-digit year:

```bash
curl --get \
  --url https://empay-api-docs-demo.vercel.app/api/attendance/my \
  --header 'Authorization: Bearer empay_portfolio_demo' \
  --data-urlencode 'month=8' \
  --data-urlencode 'year=2026'
```

A successful response returns `success: true` and three attendance records whose
dates use the requested month and year. Repeating the same request returns the
same fictional records.
Use the [interactive attendance request](/api-reference/attendance/my) to inspect
the simulated response without production access.

## If the request fails

- `400`: use a month from `1` to `12` and a year from `2000` to `9999`.
- `401`: add the bearer token returned by mock login or correct an invalid token.
- `405`: send a `GET` request.

For other problems, follow [Troubleshooting](/troubleshooting).
